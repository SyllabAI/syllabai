## Context (the re-derived finding)

The deep audit of the learner model (2026-10-01) named S2 "calibration". Durable traces after the reset — ADR-031/032 ("a natural candidate for S2 recalibration"), `BktEngine.mastered()`'s own javadoc ("Master Spec leaves banding as a v0 heuristic **pending calibration**"), and Master Spec §BKT's explicit promise of "**monthly parameter recalibration**" (§5.5 charters the research layer with "calibration") — all point at the same debt. Re-derivation from source found two concrete halves:

1. **The emission model was format-blind.** Every marked attempt updated BKT with the same `guess=0.25, slip=0.1` — but 0.25 is exactly the **four-option MCQ** guess base; the paper parameter was silently a format constant. `AssessmentEvidenceRecordedEvent` carried only a boolean `correctness` while `Question.Type` distinguishes MCQ_SINGLE / SHORT_ANSWER / STRUCTURED. Consequences, live on the hub's Smart-Mark structured path:
   - A correct structured answer at l₀=0.1 read **0.357** mastery; the same performance with a structured-appropriate guess (0.01) reads **0.918** — a **2.57× under-credit**. Structured-heavy learners sat low-biased: review over-scheduling, NBA weak-mastery over-firing, teacher heatmaps reading low.
   - A wrong structured answer was **over-forgiven** (prior 0.5 → 0.206 instead of 0.183): a worked answer treated as if a quarter of non-knowers produce one.
   - 3- and 5-option MCQs were mispriced in opposite directions (1/N ≠ 0.25).
2. **The calibration loop had no instrument.** Nothing anywhere measured predicted-vs-observed — the mis-calibration was invisible *by construction*.

The **design challenge (2026-10-02, operator-directed) verified every emission pin by hand and then found two blockers in the instrument-as-first-drafted plus one live defect class**, folded into this ADR as amendments C1–C3 below. The partial-credit rule in `EvidencePublisher.publishGraded` (full marks = correct, else wrong) was reviewed and is **documented, deliberate, and conservative** — unchanged here; relaxing it to graded evidence is a separate product decision.

## Accepted

1. **Guess is priced per format; slip, l₀ and T stay global.** The evidence event carries `questionType` + `optionCount` (both already in the publisher's hand — null-safely read: the publisher is the last line of defense for the submission path, and an unexpected null type degrades to the untyped paper emission rather than 500-ing the attempt). `LearnerProperties.Bkt.toParams(type, count)` resolves: **MCQ_SINGLE → 1/optionCount** (the paper's 0.25 is exactly N=4, so four-option MCQs are bit-identical to the legacy path), **SHORT_ANSWER → 0.05** (provisional — see challenge C5), **STRUCTURED → 0.01** (new lenient properties). Null/blank/unknown format → paper default 0.25, so untyped or future evidence keeps exact prior behaviour — a strict refinement, never a behaviour change for untyped events. Slip stays global (mistakes happen in every format). `BktEngine` math is untouched; the resolution composes through `BktParams`.
2. **Domain guards on the resolution (challenge C3).** An MCQ count below 2 degrades to the paper default: `1/1 = 1.0` would make **wrong answers RAISE mastery** (the `BktEngine` wrong-path evidence divides by `1−guess`), and `1/0` would throw inside `BktParams` validation and 500 the submission mid-update — malformed counts are the normal teacher-authored/ingested data tail (the ingest lane landed the day before), not a config error, so the guard degrades instead of failing. Every resolved guess is additionally clamped strictly below `1 − slip`: at guess ≥ 1 − slip a wrong answer stops being evidence of anything, and above it wrong answers raise mastery — a misconfigured knob must degrade, never invert the update. The full unit suite caught the type-level variant live during the rebuild (two mocked-`Question` tests NPE'd the submission path): the guard posture is "degrade, never crash".
3. **Decay enters the practice update, computed never persisted (challenge C1).** The single BKT update site previously fed the **raw ADR-031 anchor** as the prior, so the practice gap never entered the learning trajectory: correct-after-180-days read identically to correct-after-10-seconds (anchor 0.9 → 0.973 legacy vs **0.833** coherent from the decayed 0.5496), retention evidence — the only signal that can ever calibrate the τ bands — was discarded at the only moment it exists, and the write path's prior contradicted the decayed forecast every read surface displays for the same learner-node instant (S3-1-class semantics split, on the write path). The prior is now `decayed(P₀, lastPracticedAt, occurredAt)` — computed at update time, **never written**: the posterior becomes the new anchor, τ stays frozen on P₀ (the banding rule ADR-031 pinned), and the decay floor keeps the prior at or above l₀ (the learner has demonstrably been exposed). `MasteryUpdatedEvent`/`BKT_UPDATED` telemetry gains `decayedPrior` + `gapDays` beside the raw anchor (`priorMastery` keeps its historical anchor semantics for S1 forensics); zero-gap behaviour is bit-identical; pre-S1 write-back-corrupted anchors take exactly one extra decay at their next practice — the same self-healing posture ADR-031 accepted.
4. **The calibration instrument ships with the fix, scoring the forecast the model actually acted on (challenge C2).** `LearnerModelCalibrationService` aggregates the `BKT_UPDATED` stream into **Brier**, **ECE** and ten equal-width bins (count, mean latent, mean predicted, observed accuracy, mean Brier, signed calibration error), read-only over telemetry; malformed/legacy rows are skipped honestly and counted; optional `nodeId` filter. The scored forecast is `decayedPrior` (C1) — binning the anchor would score a quantity no read surface displays and stay permanently blind to decay/τ misfit. The headline prediction is **emission-mapped per row** (`latent·(1−slip) + (1−latent)·guess` through the same resolver the update path uses): raw-latent-vs-observed carries a structural ±8-point floor that **moves when the guess mix changes** (this fix moves it), so any before/after comparison on the raw curve would be confounded by the very change it gates — and a naive retune that "closed" that gap would corrupt the latent state. The raw latent mean rides beside the mapped mean for drift forensics. Exposed at `GET /api/v1/research/learner-model/calibration` behind **TEACHER/ADMIN** (new `/api/v1/research/**` SecurityConfig matcher + method-level `@PreAuthorize`); the report carries counts, never learner identifiers. Honesty caveats on the report itself: samples are *node-outcomes*, not independent learners (one marked attempt updates every node it honestly tests) — descriptive, not i.i.d. statistics; the mapped prediction uses the *current* slip, so slip retunes change the mapping across any comparison; traffic per bin is part of the report — an empty bin is no evidence, never good evidence.
5. **Retuning stays data-gated.** "Monthly parameter recalibration" now has its measurement; actually retuning slip/τ bands/τ_s from production data remains the S2 follow-up once post-deploy calibration data accumulates. The new knobs (`shortAnswerGuess`, `structuredGuess`) and every existing one are lenient-defaulted and overridable per environment.

## Design-challenge record (2026-10-02) — what the challenge changed, and what it deferred

Challenges **C1** (update prior), **C2** (emission mapping) and **C3** (domain guards) are folded into Accepted 2–4 above. The challenge also produced recorded follow-ups:

- **C4 — gate protocol (open).** "No constant moves without a before/after Brier/ECE comparison" needs teeth: minimum samples per bin, segment axes (format, gap band, deploy segment — ADR-031 already set the segmentation precedent), and a pre-registered decision rule. At Cycle-1 volume (255 r1 placeholder-marked answers + a handful of honest r2 events) the first real report will be mostly empty bins.
- **C5 — `shortAnswerGuess=0.05` is provisional.** A guess about guesses (a-priori range 0–0.25); review at the first calibration report. The format taxonomy ≠ the guess space (numeric short answer ≈ 0; taught-vocabulary short answer > 0.05) — a v2 refinement.
- **C6 — asymmetric pricing.** The format effect is priced into guess (25× move) while the opposing slip effect is declined ("one knob at a time"); the residual net-bias sign is unknown and is a standing question for the first report (needs a format cut).
- **C7 — small-cell suppression (open decision).** The research endpoint spans all learners and is nodeId-filterable; an n<5 band could be cross-read against class surfaces to infer an individual. Decide: ADMIN-only, class-scoping, or n<k suppression.
- **C8 — scope honesty.** This ADR *reframes* S2: emission fix + instrument now; τ-band, τ_s and threshold retunes remain open behind the gate. The instrument as shipped cannot validate the τ bands alone — the gap axis is on the stream (`gapDays`) but the report does not cut by it yet; that cut is a prerequisite for any τ retune.

## Rejected

- **Format-aware `slip`** (e.g. higher slip for timed structured papers): no research basis at Cycle-1 volume; one knob at a time (C6 records the residual question).
- **Graded/partial-credit BKT updates** (using `marksAwarded/marksTotal` as a soft outcome): changes the evidence semantics the §12 contract documents ("conservative, BKT-safe"); a product decision, not a calibration fix.
- **P(correct) read mapping** (surfaces displaying `P·(1−slip) + (1−P)·guess` instead of P(known)): right to reject for *read surfaces* (S3-1 "one semantics everywhere") — and deliberately NOT applied to the instrument's internal math, where the emission mapping is the correct comparator (C2). The rejection does not transfer.
- **Backfilling historical mastery** by replaying attempts under the new emission: the evidence stream is replayable in principle but the write-back-era S1 corruption makes reconstructed anchors unreliable (same conclusion as ADR-031's deferred backfill); next-attempt self-healing is accepted.
- **Force-replacing the original `fae913f` branch**: an active lane's remote work is never destroyed without operator direction; the rebuild ships as `-v2` and the PR decides.

## Consequences / migration notes

- **No schema migration.** Both events are in-JVM; telemetry payload is jsonb (new fields are optional and untyped consumers ignore them); properties are lenient-defaulted.
- **Behaviour shift is immediate and upward for structured-active learners** (the under-credit is removed): mastery jumps at the learner's *next* attempt; band assignment (τ selection) and review scheduling follow at the same moment.
- **A second, downward shift rides C1**: learners returning after long gaps now update from the decayed forecast, so their next-attempt anchor lands **lower** than the legacy chain would have written (0.833 vs 0.973 in the worked example) — correct answers after long gaps no longer ratchet the anchor up. Analytics comparing raw historical mastery must segment at the deploy date **for both reasons**; the calibration report's before/after comparisons inherit the same segmentation duty.
- **MCQ pricing changes for N ≠ 4** (3-option items read slightly lower, 5-option slightly higher on a correct answer); 4-option MCQs are bit-identical to the old path (1/4 = 0.25).
- **The calibration report becomes the gate for all future parameter retunes** (τ bands, τ_s, slip) — with the C4 protocol (min samples, segments, decision rule) defined before the first real retune request, and the gap-axis cut built before any τ-band proposal.
